Kumar Electronics & Electricals – Service Ticket Management System
Overview

Kumar Electronics & Electricals is a responsive web application developed for managing customer service requests and electrical equipment support tickets. The system allows customers to raise service tickets for products like batteries, inverters, UPS systems, stabilizers, and solar equipment.

The project is designed using React.js for the frontend and can be integrated with Django and PostgreSQL for backend and database functionality.
